## Immediate decision loop

1. IVADO: obtain the user's official accuracy and F1 for the V1 baseline, then compare a small preregistered set of meaningfully different candidates. The target is **strictly above 94% hidden-reference leaderboard accuracy**. Track feedback and submission limits; never substitute historical committee agreement or self-generated references for that score.
2. OptiFrame: protect contour-to-STL geometric fidelity and validate the physical rig before promising lens tolerances. Use genuinely new sealed fixtures, not a retrospective split of cases already used for tuning.
3. DayOne: create independently reviewed ground truth with patient-grouped splits before assessing recognition accuracy. Keep personal/health data out of external services and analytics.
4. NOVA: validate evidence and answers before adding presentation complexity.
5. Propolys: test problem ownership and workflow demand using synthetic demonstrations; security guidance is context, not proof of market demand.

Three lower-cost subagents drafted isolated challenge batches. Parent review requested changes for overlapping mechanisms, mislabeled metrics, reused holdouts, unsupported evidence and unclear predecessor distinctions. All new strategy results remain **NOT RUN**. The original hundred-strategy implementation campaign is still incomplete.
