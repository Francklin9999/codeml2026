# Structural model hypotheses

The verified best remains 94.88% accuracy / 94.66% macro F1. This batch broadens
the learned feature relationships after the nearby spline variants stalled.
All eight models have now been scored. None surpassed the incumbent; no hidden rule or 95.5% result is claimed.

All eight files contain 4,000 original candidate IDs and 1,600 grants. Each is
generated by a persisted model fitted to original historical labels. Fitting
does not load preview results, earlier predictions, or reconstructed labels.

Suggested comparison order:

| File | Hypothesis |
|---|---|
| `region_correction_90.csv` | Remove 90% of the learned direct regional term; retain 10% |
| `region_correction_95.csv` | Remove 95% of the same term |
| `region_correction_85.csv` | Remove 85% of the same term |
| `regional_merit.csv` | Center academic scores and work hours using training-only means per regional group |
| `regional_standardized.csv` | Center and scale those features within regional groups |
| `tensor.csv` | Learn smooth academic-score/work-hour interactions |
| `quadratic.csv` | Learn quadratic effects and an academic-score/work-hour interaction |
| `legitimate_context.csv` | Explore retaining fitted programme and first-generation effects |

The correction-strength settings are global mitigation hyperparameters; their
effect sizes are estimated from historical data. They are hypotheses about how
much observed regional association to remove, not evidence that the retained
part is fair or part of the reference. Their policy implications and equity
metrics require assessment alongside any accuracy improvement.

Regional merit models keep each applicant's regional group only for the
training-fitted merit transformation; the direct committee regional term is
averaged over common training profiles. Additional-context retention is also an
explicit modeling assumption rather than a claim that these attributes should
affect financing decisions in production.

Configuration selection uses the existing five development folds. The regional
centering model modestly improved historical development log loss (0.256519
versus 0.256633 for the original sparse spline). That difference does not
establish a significant improvement or higher hidden-reference accuracy.

Feature independence does not prove that a feature is unused by an unknown
reference target. These comparisons test relationships that the earlier
academic/work-only correction suppressed. They do not recover a generator seed
or infer individual reference labels.
