# Refined learned models

The platform has now scored all three models:

| Model | Accuracy | Macro F1 |
|---|---:|---:|
| Sparse spline | **94.88%** | **94.66%** |
| Bootstrap spline ensemble | 94.78% | 94.56% |
| Monotonic trees | 94.33% | 94.09% |

The sparse spline is the best verified clean model. The >95% target has not
been reached. Observations and file hashes are in
`work/codex_model/platform_results.csv`.

Model descriptions:

1. `bagged_spline.csv`: average of 20 spline models fitted to bootstrap samples
   of the historical data. Fewer nuisance terms reduce estimation variance.
2. `monotonic.csv`: boosted trees constrained so higher academic scores and more
   work effort cannot reduce the corrected score, all other features held fixed.

`sparse_spline.csv` is the unbagged spline comparator. Every CSV is generated by
a persisted, reusable model and contains 4,000 rows with 1,600 grants. There are
no manual label overrides or evaluation-label reconstruction.

Training uses original historical committee labels. The family settings are
selected using the original development folds, without revisiting holdout
outcomes. The earlier platform score motivates comparing these different model
families, but is not a fitting target. Neither scores nor earlier prediction
files are read by the refinement training script.

Development log loss against historical committee decisions:

| Model | Log loss |
|---|---:|
| First ensemble | 0.256891 |
| Bootstrap spline ensemble | 0.256715 |
| Monotonic trees | 0.263429 |

These are development-selection metrics, not independent test metrics or
hidden-reference accuracy. Historical fit alone cannot choose the most accurate
correction for a different target. The mitigation assumption remains: retain
academic score and work hours; average all other effects over training profiles.

From `equialgo-participants/`, retrain and reproduce this batch:

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python model_ensemble.py refine
```

To predict with the already fitted bootstrap ensemble:

```bash
python model_ensemble.py predict \
  --model work/codex_model/refinement/bagged_spline.joblib \
  --input data/candidats_evaluation.csv \
  --output upload_model_round2/bagged_spline.csv
```
