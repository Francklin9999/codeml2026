# Current verified clean model

`predictions.csv` is generated by the saved sparse spline model. It reproduces
the platform-scored `upload_model_round2/sparse_spline.csv` byte for byte:
**94.88% accuracy and 94.66% macro F1**. The >95% goal is not yet reached.

It contains 4,000 candidate IDs and 1,600 grants. The model was fitted to original
historical labels and scores applicants from features. No evaluation labels or
manual applicant corrections enter its training or inference.

Reproduce from `equialgo-participants/`:

```bash
python model_ensemble.py predict
```

The model path and artifact hash are recorded in
`work/codex_model/best_model.json`. Use `--input` and `--output` to score a new
cohort with the same trained model.
