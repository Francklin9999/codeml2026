# Predictions from fitted models

`predictions.csv` and `ensemble.csv` are identical: the ensemble selected using
historical development validation. Start with this file for a platform preview.

`linear.csv`, `spline.csv`, and `boosted.csv` come from the independently selected
best configuration in each family. They are competing fitted-model hypotheses;
historical validation does not establish their ranking on the jury's reference.

Every file contains 4,000 input IDs in their original order and 1,600 grants.
All decisions are generated by saved, reusable models fitted to historical
training labels. No CSV corrections or reconstructed evaluation labels are used.

The platform measured `ensemble.csv` at **94.63% accuracy and 94.40% macro F1**.
The 95% goal has not been reached. The selected ensemble's 88.65% historical
holdout accuracy concerns the committee's different, biased label target.
The linear, spline, and boosted family outputs have not yet been scored in
this run. The platform observation is recorded with the output hash in
`work/codex_model/platform_results.csv`.

Reproduce from `equialgo-participants/`:

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python model_ensemble.py predict \
  --model work/codex_model/artifacts/ensemble.joblib \
  --output upload_model/ensemble.csv
```

See `work/codex_model/README.md` for training, ensemble weights, validation, and
the correction assumptions.
